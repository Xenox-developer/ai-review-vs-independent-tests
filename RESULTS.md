For `{"path":"%ff"}`, initial and review solutions reject invalid UTF-8 with
UnicodeDecodeError. Its inheritance is:

```text
UnicodeDecodeError → UnicodeError → ValueError → Exception
```

The frozen primary evaluator compares the exact exception name to ValueError.
Normal `assertRaises(ValueError)` accepts subclasses. The written contract did
not require an exact class. The test-guided repair adds:

```python
try:
    path = unquote(data['path'], encoding='utf-8', errors='strict')
except UnicodeDecodeError as error:
    raise ValueError('invalid UTF-8 in path') from error
```

This satisfies the stricter grader, and does not demonstrate a behavioral repair
advantage under the written contract. Generated examples triggering this change
were `a/%FF`, `%C3%28` and `%ED%A0%80`. The fixed held-out suite includes `%ff`.
All other task outcomes agree between the independently implemented scorers.

Review judged all initial candidates likely_correct with zero issues. Only the
tests-arm safe-path source changed; every review source and the other seven
tests-arm sources are byte-identical to their initial candidates. There were
no score regressions. Raw false-confidence/incorrect labels in scores.json are
strict-oracle labels, not demonstrated behavioral failures.

The interpretation issue was recorded during static checker review before
held-out scoring or reading candidate source. The independent scorer was written
before viewing final outcomes. Original candidates, checker, prompts and tasks
were not changed. No new model run, seed or task was added. Both scoring reports
use the same Docker image, and all 24 source hashes were checked. Exit 1 from
the independent scorer means it reproduced the documented disagreement.

Primary 7/7/8 remains in results/scores.json; 8/8/8 sensitivity is in
results/independent-recalculation.json. results/audit.json verifies coverage,
original aggregation, hashes, identical branch inputs and distinct contexts.
The factual chart is generated by lab/plot.py from both saved reports.

Eight AI-authored synthetic tasks and one model are insufficient for a production
ranking. All initial candidates already pass the finite checks with normal error
handling, leaving no demonstrated behavioral defects for either treatment to
repair. Reference qualification is an additional oracle-assisted component.
These diagnostic findings do not establish that review or testing is unnecessary.
